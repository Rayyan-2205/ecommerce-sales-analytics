# 🛒 E-Commerce Sales Analysis

An end-to-end exploratory data analysis (EDA) project built using **Python**, **NumPy**, **Pandas**, and **Matplotlib**. This project analyzes an e-commerce dataset to uncover insights about sales performance, customer behavior, product trends, and delivery operations.

---

## 📌 Project Objective

The goal of this project is to clean, merge, and analyze multiple e-commerce datasets to answer real business questions such as:

- Which product categories generate the highest revenue?
- Which states contribute the most sales?
- How do customer purchasing patterns change over time?
- How efficient is the delivery process?
- What insights can help improve business decisions?

---

## 📂 Dataset

This project uses the **Brazilian E-Commerce Public Dataset by Olist**.

The dataset contains information about:

- Customers
- Orders
- Order Items
- Products

These datasets were merged to create a single master dataset for analysis.

## 📊 Project Workflow

### 1. Data Cleaning

- Checked missing values
- Converted datetime columns
- Verified duplicate records
- Investigated inconsistent timestamps
- Performed data quality validation

### 2. Data Merging

Merged multiple datasets using relational joins:

- Customers
- Orders
- Order Items
- Products

Created a master dataset containing all relevant business information.

### 3. Exploratory Data Analysis

Performed analysis on:

- Business Overview
- Revenue Analysis
- Product Analysis
- Customer Analysis
- Order & Time Analysis
- Delivery Analysis

### 4. Data Visualization

Created visualizations using Matplotlib to present key business insights.

---

## 📈 Key Insights

Some important findings from the analysis include:

- São Paulo generated the highest number of orders and revenue.
- Beauty & Health was the highest revenue-generating category.
- Bed, Bath & Table had the highest sales volume.
- Most customers placed only one order.
- Customer purchases were highest during weekdays and business hours.
- Over 97% of orders were successfully delivered.
- More than 100,000 orders were delivered on or before the estimated delivery date.
- A small number of timestamp inconsistencies were identified and investigated during the delivery analysis.
